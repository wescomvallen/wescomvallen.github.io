Updates to PaperGUI

About PaperGUI

by Vallen Alexander - 17 October 2026

PaperGUI is a graphical user interface (GUI) framework made in Scratch designed to make dynamic UI easier for developers, and more intuitive towards the user. PaperGUI includes a set of features already built in to speed up project development, while also allowing for more types of UI elements to be used on a project.

Posting Community Weblog Articles

To add an article to Cellulose3D Interactive's web log, you can request to add it by sending an email to my contact address here.

Just send the article document in clear and readable .doc or .pdf, maybe even a .txt file, and some pictures if you want. Your article should be up in just one week.

Note that you can only post one blog post per week.

Articles must comply with our Content Code to be uploaded to our web log. Existing articles violating the Content Code will be removed.
If an article exists violating our Content Code, please email vallenalexander2428@gmail.com to request removal.
