About PaperGUI

This page is dedicated for Cellulose3D Interactive's legal policies regarding usage of our digital works, moderation of community content, usage of our documentation, and more.

As of right now, PaperGUI is still in development and anything listed here are subject to change. We'll keep you updated with the development, but if you really want to see the latest, you can join our Discord server.

PaperGUI vs FlexiGUI

PaperGUI is a completely new UI framework project designed to provide better performance, more intuitive development workflow, and more UI elements than what FlexiGUI offers.

  • PaperGUI uses a more efficient way to render its UI elements, with elegant code that is easy to modify.
  • PaperGUI will feature more UI elements that allow for a more customizable and flexible user interface.
  • PaperGUI will feature more input elements that allow better user interaction.
  • PaperGUI will have a special edition that adds assistive technologies, keyboard-only navigation, and improved accessibility features.
  • PaperGUI is designed for adaptation, so every project can use their own modified versions with features not present on the default versions.
  • PaperGUI will fix various rendering issues present in FlexiGUI, allowing for more accurate colors, pretty text wrap, and more.

Promised Feature Set

These are all the features PaperGUI will promise to have.

  • Refined UI forms for data-holding UI elements
  • On-screen keyboard for touch devices (Scratch's default dialogue box is hard to use on small displays)
  • All of these UI elements:
    • Text Label
    • Stamped Costume
    • Simple shapes: Rectangles, Lines, Circles, etc.
    • Text Buttons
    • Image Buttons
    • Checkboxes
    • Toggle switches
    • Radio buttons
    • Dropdown menus
    • Combo boxes
    • Input field for text, password, date, time, etc.
    • Link text
  • ..and more UI elements that I may not have thought of.

Projects that will be released with PaperGUI
